# 魔桶制作 Skill 🐚🚽

**纯软件版：仅包含电子交互 Skill、固件、素材工具和音效，不包含外壳模型、CAD 或打印资料。**

**选四件幸运物，上传自己的照片，用 AI 做一个属于你的赛博马桶。**

由 [IcyBarbie](https://github.com/icybarbie) 创作，借助 Codex 开发。这里分享的是可定制的电子交互流程和源码；每个人可以使用不同的四件物品和照片。

## 怎么玩

点麦克风 → 模拟听你说话 → 显示固定提问 → 四件幸运物快速滚动并随机停下一件，伴随短放屁音效。再点麦克风 → 显示“谁是这个世界上最好看的人”的固定提问 → 出现你的照片。点脸，把自己冲走。

有魔法、水、放屁、冲水四类音效；长按麦克风约 850 毫秒静音。**这是模拟语音演出，不录音、不识别语音，设备运行不需要云端 AI。**盖子开合目前不会自动触发程序。

## 需要准备

- 微雪 **ESP32-S3-Touch-AMOLED-1.75C**，保留原金属外壳。型号里的 C 不能省略，其他板型要另行适配。
- 四件幸运物的名称和你自己的照片。
- 可以执行本地文件和命令的 AI 编程工具；生成图片或抠图需要对应图像工具，也可以自己提供五张透明 PNG。
- 数据线和电脑。

## 给 AI 怎么说

在 GitHub 点 **Code → Download ZIP**，解压，把文件夹交给 AI 打开，然后复制这段：

> 请先读取这个文件夹里的 SKILL.md，使用魔桶制作流程。我的四件幸运物是草莓、钥匙、星星和唱片，人物用我提供的照片。开发板是微雪 ESP32-S3-Touch-AMOLED-1.75C。先帮我准备和预览素材，再编译；等我明确要求上板时再操作开发板。

支持 skill 安装的工具，可以把此文件夹安装为 `magic-toilet-maker`；Codex 可以通过 skill 安装器使用这个仓库。其他 AI 也能读取同一份 Markdown 指令，不要求使用 Codex。纯聊天工具可以指导操作，但无法直接替你操作本机或开发板。

默认界面是清透 Low Poly 水面、移动小三角高光、荧光绿／铬银 UI，以及粗糙照片抠图。默认两句台词为中文，想换成英文需要同时调整换行与显示时长。只改四个名称不会改变图片，需要准备对应的图案。

首次烧录前完整备份自己的板，不使用别人的设备备份。

本仓库仅分享电子交互软件，不提供作者的外壳模型、铰链、打印件、建模源码、制造尺寸或装配资料。请勿从作者的其他本地项目复制或发布这些资料。

作者原版已上板，自定义素材流程已编译验证；不代表每个新用户的板都已经实测。通用烧录工具尚未在第二块实体板验证，Windows/Linux 的设备操作也尚未实测。
